Syarat & Ketentuan per Invoice

Mockup v1 — bukan kode aplikasi. S&K diisi dari template default (Admin → Invoice), lalu bisa diubah per invoice di bagian paling bawah form, setelah item barang. Klik tombol di bawah untuk pindah layar; semua kolom di layar 1 bisa dicoba.

Default = template Admin → Invoice Semua role (Sales, Admin, Owner) boleh ubah Draft ikut template · Belum bayar/DP/Lunas dibekukan Lunas → tidak bisa diubah Satu template default
Form invoice. Seksi baru "Syarat & Ketentuan" ada di paling bawah, setelah item + total, sebelum tombol Simpan. Defaultnya tertutup (supaya form di HP tidak makin panjang) dan ringkasannya menunjukkan apakah masih ikut default atau sudah custom. Coba: buka, ubah satu baris, lalu klik "Kembalikan ke default".

Syarat & Ketentuan Default
Perubahan di sini hanya berlaku untuk invoice ini. Template default diatur di Admin → Invoice.
Aturan per status. Teks template hanya diikuti selama invoice masih draft. Begitu invoice dikirim (Belum bayar), teks yang berlaku saat itu dibekukan di invoice dan tidak pernah ikut berubah lagi. Invoice Lunas tidak punya form ubah sama sekali (halaman ubah = 404, server menolak), jadi S&K-nya hanya terlihat di detail dan PDF.
